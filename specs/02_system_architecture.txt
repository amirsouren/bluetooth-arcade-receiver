===============================================================================
SYSTEM ARCHITECTURE & DIRECTORY STRUCTURE
===============================================================================

1. LAYERED ARCHITECTURE

       +-------------------------------------------------------------+
       |                  PRESENTATION LAYER (QML)                   |
       |  - ArcadeWindow.qml    - RetroButton.qml    - VUMeter.qml   |
       +-------------------------------------------------------------+
                                     │ (Qt Property Bindings / Signals)
                                     ▼
       +-------------------------------------------------------------+
       |             UI CONTROLLER LAYER (PySide6 / Python)          |
       |  - AppController (QObject exposing props to QML)             |
       +-------------------------------------------------------------+
                                     │ (Python Events / Observer)
                                     ▼
       +-------------------------------------------------------------+
       |                      SERVICES LAYER                         |
       |  - BluetoothService     - MediaControlService               |
       |  - AudioRoutingService  - MetadataCache                     |
       +-------------------------------------------------------------+
                                     │
                   ┌─────────────────┴─────────────────┐
                   ▼                                   ▼
       +------------------------+          +------------------------+
       |  System D-Bus (BlueZ)  |          |  PipeWire / WirePlumber|
       |  org.bluez.MediaPlayer |          |  (Audio Sink routing)  |
       +------------------------+          +------------------------+
